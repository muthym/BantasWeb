BANTAS Command Helper

Welcome to BANTAS! These are the special symbols you can use to tell the computer what to do. Each symbol is a powerful command!

A Quick Note on Magic Boxes (Stacks)

Remember, Bantas uses magic boxes called stacks to save information.

  • Look Inside a Box (`@`): When you see @<index> (like @1), it means: "Look inside box #1 and use whatever value is stored there."
  • **The Loop Counter (`@,0`):** Inside a loop (the [ and ] commands), @,0 refers to the number the loop is currently counting.

Using Quotes (For Words)

Always put quotes (") around a word if you want the computer to treat it as a word, like <,"Hi".

Core Commands (Talking and Saving)

@ - Set Active Box
@,<position>

What it does: Tells the computer which magic box (stack) you want to use next. All other commands will work on this box.

Example: @,5 sets the active box to number 5.

< - Put Value in Box
<,<value>

What it does: Puts a number or a word inside the magic box you're pointing at.

Example: <,100 stores the number 100. <,"hello" stores the word "hello".

> - Ask Me for Input
>,<prompt_message>

What it does: **Asks** the user to type something and puts their answer in the active box.

Example: >,"What is your name?"

? - Say/Print (New Line)
?,<value>

What it does: **Says** the word or number to the screen, then moves to a new line for the next message.

Example: ?,@1 prints the value from box 1.

?? - Say/Print (Same Line)
??,<value>

What it does: **Says** the word or number without moving to a new line, so the next thing prints right next to it.

Example: ??,"Hi " followed by ??,"There" prints "Hi There".

Math Commands (Doing Calculations)

These commands change the number inside the active box using the number you provide.

+ - Add
+,<value>

What it does: **Adds** the argument's number to the number already in the active box.

Example: +,10 adds 10 to the active box.

- - Subtract
-,<value>

What it does: **Subtracts** the argument's number from the number already in the active box.

Example: -,5 subtracts 5 from the active box.

* - Multiply
*,<value>

What it does: **Multiplies** the active box's number by the argument's number.

Example: *,2 doubles the value in the active box.

/ - Divide
/,<value>

What it does: **Divides** the active box's number by the argument's number (gives a decimal answer).

Example: /,2 halves the value in the active box.

// - Chunky Divide (Integer)
//,<value>

What it does: **Divides**, but only keeps the whole number answer. (e.g., 10 // 3 equals 3).

/// - Leftover Divide (Modulo)
///,<value>

What it does: **Divides**, but only keeps the remainder (the leftover part). (e.g., 10 /// 3 equals 1).

^ - Power Up! (Exponent)
^,<exponent>

What it does: **Multiplies** the number in the active box by itself a certain number of times.

Example: ^,3 cubes the value (value * value * value).

$ - Random Number
$,<max_value>

What it does: Generates a random whole number (like rolling a die) between 1 and the number you give, and stores it in the active box.

Example: $,100 stores a random number between 1 and 100.

Word Commands (String Magic)

& - Join Words (Concatenate)
&,<value>

What it does: **Joins** the word you provide to the end of the word already in the active box.

Example: If box 1 has "Hello", &, World changes it to "Hello World".

>< - Tidy Up (Trim)
><,<string_value>

What it does: **Cleans up** a word by removing any extra spaces at the very beginning or very end.

Example: If box 1 contains " hello ", ><,@1 will change it to "hello".

_ - Measure Word (Length)
_,<string_value>

What it does: **Counts** how many letters are in a word and puts that number into the active box.

Example: _,Hello stores the number 5.

( - Take from Left
(,<length>

What it does: **Keeps** only the first few letters from the left of the word in the active box.

Example: If the active box has "abcdef", (,3 will change it to "abc".

) - Take from Right
),<length>

What it does: **Keeps** only the last few letters from the right of the word in the active box.

Example: If the active box has "abcdef", ),2 will change it to "ef".

Control Flow (Making Choices and Repeating)

[ and ] - Loop/Repeat
[,<start_value> ... ],<end_value>

What it does: Makes the computer repeat a set of commands multiple times, like counting from one number to another.

Example:

' This loop counts from 1 to 5
[,1
  ?,@
],5
#, !, ; - If/Else/End Check
#,<condition> ... ! ... ;

What it does: Makes the computer check if something is true and choose which commands to run.

  • # (If): Do this block of code IF the condition is true.
  • ! (Else): Do this block of code OTHERWISE (if the condition was false).
  • ; (End If): Marks the END of the choice.

Example:

@,1
<,10
#,=10
 ?,Value is 10
!
 ?,Value is not 10
;

Trigonometry Commands (Advanced Math)

Note: These commands use degrees (like in a circle) to figure out an answer and store it in the active box.

{ - Sine
{,<degrees>

What it does: Calculates the Sine (a special math value) from the degrees you give it and stores the answer in the active box.

Example: {,90 stores 1 in the active box.

} - Cosine
},<degrees>

What it does: Calculates the Cosine (another special math value) from the degrees you give it and stores the answer in the active box.

Example: },0 stores 1 in the active box.

\ - Tangent
\,<degrees>

What it does: Calculates the Tangent (a third special math value) from the degrees you give it and stores the answer in the active box.

Example: \,45 stores 1 in the active box.

Type and Format Commands (Changing Value Types)

. - Letter to Secret Number
.,<character>

What it does: Converts a single letter (like 'A') into its secret computer number (ASCII value) and stores that number in the active box.

Example: .,A stores the number 65 in the active box.

: - Secret Number to Letter
:,<byte_value>

What it does: Converts a secret computer number (like 65) back into its single letter ('A') and stores that letter in the active box.

Example: :,65 stores the letter "A" in the active box.

% - Format Value
%,<format_code>

What it does: Changes how a number or word looks (formats it). You can make words all uppercase or give numbers decimal places.

Notes on Number Templates:

  • The format 0 is a placeholder that **adds extra zeros** (like 0.00 turns 7.5 into 7.50).
  • The format # is a placeholder that **does NOT add extra zeros**.

Examples:

  • %,U makes the word in the active box **UPPERCASE**.
  • %,L makes the word in the active box **lowercase**.
  • %,C makes the word in the active box **Capital Case** (e.g., hello world becomes Hello World).
  • %,I Formats a number as an **Integer** (no decimals, e.g., 10.5 becomes 11).
  • %,F2 formats a number to have **2 decimal places** (like 10.00).
  • %,M2 formats a number using a standard **Money format with commas** (e.g., 1234567 becomes 1,234,567).
